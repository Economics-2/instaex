# Insta — ভিডিও ডাউনলোডার (Windows)

তৈরি করেছেন **MH & MIK**

yt-dlp ও ffmpeg অ্যাপের ভেতরেই বান্ডেল করা। ফিচার: ভিডিও/অডিও (MP3) ডাউনলোড, প্লেলিস্ট (সর্বোচ্চ ৫০টি, জিপে), সাবটাইটেল (.srt), ডাউনলোড ইতিহাস, "ফোল্ডারে দেখান" বাটন, yt-dlp আপডেট বাটন।
ডাউনলোড করা ফাইল কম্পিউটারের **Downloads\Insta** ফোল্ডারে জমা হয়।

## GitHub থেকে .exe বানানোর ধাপ (Python বা Visual Studio লাগবে না)

1. এই ফোল্ডারের **সব ফাইল ও ফোল্ডার** (লুকানো `.github` সহ) রিপোর রুটে আপলোড করুন।
   টার্মিনাল থাকলে:
   ```
   git init
   git add .
   git commit -m "Insta Windows"
   git branch -M main
   git remote add origin https://github.com/Economics-2/insta.git
   git push -u origin main
   ```
   রিপোতে আগে থেকে ফাইল থাকলে প্রথমে `git pull origin main --allow-unrelated-histories` চালিয়ে তারপর push করুন।
   ওয়েবে আপলোড করলে `.github/workflows/build-exe.yml` ফাইলটি অবশ্যই যেন যায়।
2. রিপোর **Actions** ট্যাবে "Build EXE" চলবে (৫–১০ মিনিট)। না চললে Actions থেকে "Run workflow" চাপুন।
3. সবুজ টিক এলে রিপোর **Releases → Insta (Windows) — Latest** থেকে `Insta.exe` ডাউনলোড করুন।
   (প্রাইভেট রিপো হলে GitHub-এ লগইন করা অবস্থায় ডাউনলোড করুন।)
4. `Insta.exe`-তে ডাবল-ক্লিক করলেই চালু হবে। ইনস্টলের দরকার নেই।

বিল্ডের শেষ ধাপে exe নিজেই নিজেকে পরীক্ষা করে (সার্ভার, yt-dlp, ffmpeg, WebView2 লাইব্রেরি)। কিছু ভেঙে থাকলে বিল্ড লাল হবে, আর লগে কোন ধাপ ব্যর্থ হয়েছে দেখা যাবে।

## Chrome এক্সটেনশন (ফেসবুক, ইনস্টাগ্রাম, ইউটিউব থেকে এক ক্লিকে)

এক্সটেনশন চালু থাকলে ভিডিও পেজে **"Insta-তে ডাউনলোড"** বাটন আসে। চাপলে লিংক Insta অ্যাপে যায় এবং **সেরা কোয়ালিটিতে সাথে সাথে ডাউনলোড শুরু** হয়। অ্যাপের ভেতরে "এক্সটেনশন থেকে ডাউনলোড" অংশে অগ্রগতি দেখা যায়।

**ইনস্টল (একবারই):**
1. Insta.exe চালু করুন। নিচে "Chrome এক্সটেনশন" অংশটি খুলে **এক্সটেনশন ফোল্ডার খুলুন** চাপুন (ফোল্ডারটি `%APPDATA%\Insta\extension`)।
2. Chrome-এর ঠিকানার ঘরে `chrome://extensions` লিখে Enter চাপুন।
3. ডানে উপরে **Developer mode** চালু করুন।
4. **Load unpacked** চেপে ওই `extension` ফোল্ডারটি বেছে নিন।
5. টুলবারে ধাঁধার আইকন থেকে Insta-কে পিন করে রাখতে পারেন।

**ব্যবহার:**
- ইউটিউব ভিডিও/Shorts, ফেসবুক ভিডিও/Reel, ইনস্টাগ্রাম Reel/পোস্ট খুললে নিচে ডানে বাটন আসে।
- ফেসবুক/ইনস্টাগ্রামের ফিডে ভিডিও পর্দায় থাকলেও বাটন আসে (ভিডিওর নিজস্ব লিংক পাওয়া গেলে)। সাইট ডিজাইন বদলালে এটি কাজ না-ও করতে পারে, তখন ভিডিওটি খুলে নিন।
- যেকোনো লিংকে বা পেজে **ডান-ক্লিক → "Insta-তে ডাউনলোড করুন"**।
- টুলবারের Insta আইকন চাপলে "এই পেজটি পাঠান" বাটন ও অ্যাপ চালু আছে কিনা দেখা যায়।
- **Insta.exe চালু না থাকলে** বাটন "Insta অ্যাপ চালু নেই" জানাবে।
- লগইন-লাগা বা প্রাইভেট ভিডিওর (বিশেষ করে ইনস্টাগ্রাম) জন্য টুলবার আইকনে **"লগইন কুকি সাথে পাঠান"** টিক দিন। কুকি শুধু আপনার কম্পিউটারের Insta অ্যাপে যায়।

**নিরাপত্তা:** অ্যাপ শুধু এই এক্সটেনশনের (নির্দিষ্ট ID-র) অনুরোধ নেয়। অন্য কোনো ওয়েবসাইট বা এক্সটেনশন Insta-কে দিয়ে ডাউনলোড চালাতে পারে না।

## নিজের কম্পিউটারে বানাতে চাইলে (ঐচ্ছিক)
1. Python 3.12 ইনস্টল করুন (Add to PATH টিক দিয়ে)।
2. `bin\` ফোল্ডারে `yt-dlp.exe` (github.com/yt-dlp/yt-dlp/releases) ও `ffmpeg.exe` (github.com/yt-dlp/FFmpeg-Builds/releases) রাখুন।
3. `build.bat`-এ ডাবল-ক্লিক করুন। ফল: `dist\Insta.exe`।

## বিল্ড ব্যর্থ হলে
Actions-এ লাল ক্রসে ক্লিক করে এরর লগ দেখুন এবং শেষ ২০–৩০ লাইন কপি করে পাঠান।

## ব্যবহারের টিপস
- প্রথমবার খুলতে কয়েক সেকেন্ড লাগে (ফাইল এক্সট্র্যাক্ট হয়)।
- লিংক পেস্ট করে **Enter** চাপলেই খোঁজা শুরু হয়।
- কোনো সাইট কাজ না করলে অ্যাপের নিচে "yt-dlp আপডেট করুন" চাপুন। আপডেট `%APPDATA%\Insta\bin`-এ জমা থাকে, তাই পরের বারও থাকবে।
- ডাউনলোড ব্যর্থ হলে কারণ লেখা থাকে `%APPDATA%\Insta\logs\last-error.txt` ফাইলে।

## সম্ভাব্য সমস্যা
- **Windows SmartScreen / Defender সতর্কতা দিলে:** "More info → Run anyway" চাপুন। exe-তে ডিজিটাল সিগনেচার নেই বলে এটা স্বাভাবিক, অ্যাপটি আপনার নিজের বানানো।
- **"WebView2 পাওয়া যায়নি" বার্তা এলে:** "হ্যাঁ" চেপে Microsoft-এর পেজ থেকে *Evergreen Bootstrapper* ইনস্টল করে আবার চালু করুন। Windows 11 ও আপডেটেড Windows 10-এ এটি আগে থেকেই থাকে।
- **ফাইলের সাইজ:** ffmpeg বান্ডেল থাকায় Insta.exe বড় (প্রায় ১০০–১৫০ MB)।

## জানা সীমাবদ্ধতা
- ডিজিটাল সিগনেচার ছাড়া exe, ব্যক্তিগত ব্যবহারের জন্য যথেষ্ট।
- শুধু নিজের বা অনুমতিপ্রাপ্ত কনটেন্ট নামান। কপিরাইট ও প্ল্যাটফর্মের নীতি মানা আপনার দায়িত্ব।
